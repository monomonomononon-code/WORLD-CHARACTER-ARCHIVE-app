# WORLD & CHARACTER ARCHIVE

自作キャラクター・世界観設定を管理するための、サーバー不要の静的Webアプリです。
データはすべてブラウザの `localStorage` に保存されます（サーバーへの送信なし）。

## 構成

```
.
├── index.html          エントリーポイント（HTML構造のみ）
├── css/
│   └── style.css        全スタイル
└── js/
    ├── storage.js        localStorage 読み書きのラッパー
    ├── state.js          アプリの状態・キャラクター項目定義
    ├── utils.js          共通ユーティリティ（HTMLエスケープ・トースト通知・コピー）
    ├── project.js        「作品」の一覧・出入り・移行ロジック
    ├── world.js          「世界観設定」タブのロジック
    ├── character.js      「キャラクター」タブのロジック
    ├── backup.js         バックアップの書き出し・読み込み
    └── main.js           タブ切り替え・初期化
```

## データの構造（作品 > 世界観設定 / キャラクター）

アプリを開くと、まず「作品」の一覧が表示されます。作品カードを開くと、その作品専用の「世界観設定」「キャラクター」タブに入ります。

- 世界観設定・キャラクターは、必ずどれか1つの作品に属します
- 編集モーダルの「作品」欄で、別の作品へ移動できます
- 作品名はコピー機能（まとめてコピー・全部コピーなど）の内容には含まれません（あくまで整理用の箱です）
- 過去にバージョンアップ前から使っていた場合、既存の世界観設定・キャラクターは初回起動時に自動で「これまでのデータ」という作品にまとめられます。あとから好きな作品名にリネーム、または個別に別の作品へ移動してください

## ローカルで動かす

`index.html` をブラウザで直接開くだけで動作します。

もしくは簡易サーバーを立てても構いません。

```bash
npx serve .
```

## GitHub Pages で公開する

1. このフォルダの内容をGitHubリポジトリにpushする
2. リポジトリの Settings → Pages で、Branch を `main` / フォルダを `/root` に設定
3. 発行されたURLにアクセスすると動作します

## データの保存について

- キャラクター・世界観設定は、閲覧しているブラウザの `localStorage` に保存されます。
- ブラウザやデバイスが変わると、保存されたデータは引き継がれません（別のlocalStorageになるため）。
- 「まとめてコピー」「全部コピー」ボタンでテキストとして書き出せるので、閲覧用のバックアップに活用してください。

## 他の端末（PC → スマホなど）にデータを移す

画面右上の「バックアップ」ボタンから移行できます。

1. **PC側**：「バックアップ」→「ファイルをダウンロード」で `.json` ファイルを保存し、メールやLINE、クラウドストレージなどでスマホに送る
2. **スマホ側**：同じアプリ（同じURL）を開き、「バックアップ」→ 送られてきた `.json` ファイルを選択

ファイルのやり取りが難しい場合は、「JSONをコピー」→ メモアプリなどに貼り付けて送り、スマホ側で「JSONを貼り付けて読み込む」からも読み込めます。

すでにスマホ側にもデータがある状態で読み込むと、「上書き」か「重複しない項目だけ追加」かを確認するダイアログが出ます。
